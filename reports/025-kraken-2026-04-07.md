## F) Interview Prep

### STAR+R Stories

1. **API integration delivery** — *PULSE:* Integrated PayPhone payment API into PWA, handling authentication, transaction processing, webhook callbacks, and error handling. Result: 125+ successful transactions, $2,500+ first-week revenue. *Reflection:* API integrations require understanding both the documentation and the edge cases that documentation doesn't cover.

2. **Cross-functional delivery in complex environment** — *Karpowership:* Managed 4 Powership installations coordinating 25+ contractors, international stakeholders, and government regulators during Ecuador's energy crisis. Result: All installations delivered, 90% commute reduction. *Reflection:* In regulated environments, stakeholder alignment on compliance requirements must happen before technical work begins.

3. **Full-stack system design** — *PULSE:* Designed and built complete system architecture: React 18 frontend, Node/Express backend, PostgreSQL database, REST APIs, PayPhone payment integration, PWA deployment. Result: Production system handling real money transactions. *Reflection:* System design decisions made early (like choosing PostgreSQL over NoSQL) have cascading effects on everything that follows.

4. **Security and compliance mindset** — *PULSE:* Conducted 26-item security audit covering authentication, data handling, XSS prevention, CSRF protection, payment security, and session management. Result: All items addressed before launch. *Reflection:* Security audits should be checklists, not afterthoughts — build them into the sprint plan.

5. **AI-augmented workflow** — *Glipy:* Used AI tools to accelerate solo development of Flutter/Supabase health app. Result: Production-ready app built with AI-augmented workflow. *Reflection:* AI assistance is most valuable for boilerplate and pattern recognition; human judgment remains essential for architecture and UX decisions.

6. **Capacity planning across workstreams** — *Karpowership:* Managed 4 simultaneous installation workstreams with 25+ contractors requiring different skill sets and schedules. Result: No resource conflicts, all streams delivered. *Reflection:* Capacity planning requires both the spreadsheet (resource allocation) and the conversation (understanding each person's real bandwidth).

7. **Stakeholder communication synthesis** — *Karpowership:* Translated complex technical progress into executive updates for international leadership. *Reflection:* Different stakeholders need different levels of abstraction — engineering wants details, executives want risks and timelines.

8. **Remote team velocity optimization** — *Eagle Eye:* Managed 15+ remote contractors with 2-4 day turnaround SLA across distributed locations. Optimized handoff processes to reduce delivery time. Result: 50+ clients served with consistent quality. *Reflection:* Velocity improves when you remove handoff friction, not when you add pressure.
